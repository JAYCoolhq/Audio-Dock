# AudioDock

## 功能

- **设备页**：列出所有输出和输入设备，调节音量、静音，一键设为默认设备（控制台、多媒体、通讯三个角色同时设置）。
- **应用页**：按应用聚合的音量混合器。每个应用可单独指定输出设备；开启「锁定」后，设备重连或应用重启时会自动重新应用。
- **蓝牙页**：同一副耳机的立体声、免提、麦克风端点合并显示，一键连接或断开，无需管理员权限。
- **全局快捷键**：显示/隐藏面板、循环切换输出设备、静音默认设备，可在设置页自定义。
- **托盘**：左键弹出面板；右键菜单可直接切换默认输出设备、切换固定模式、开关开机自启、退出。
- **两种窗口模式**：托盘弹出（失焦自动隐藏），或固定到任务栏（常驻窗口，记住位置）。
- **主题**：跟随系统深色/浅色。

## 使用说明

- 下载并运行 `AudioDock-<版本>.exe`，首次启动会弹出面板；之后开机自启时只在托盘静默运行。
- 在「应用」页，用下拉框为某个应用选择输出设备，立即对该应用的所有进程生效。点旁边的图钉可保存为锁定规则。
- 在「设置」页可自定义快捷键、窗口模式和开机自启；「重置应用的输出设备规则」会清除全部锁定规则，并重置系统级设置。
- 日志位置：`%APPDATA%\AudioDock\audiodock.log`。
